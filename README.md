# 🩺 Diabetes Prediction Using Machine Learning

A machine learning project that predicts whether a patient is likely to have diabetes based on health and lifestyle information.

The project includes data cleaning, preprocessing, multiple machine learning classification models, model comparison, and a Streamlit web application for making predictions.

## 📌 Project Overview

This project uses a diabetes dataset containing patient health and lifestyle information.

The workflow includes:

* Data loading and exploration
* Handling missing values
* Removing duplicate records
* Handling invalid categorical values
* Outlier detection and treatment using the IQR method
* Categorical feature encoding
* Splitting data into training and testing sets
* Training multiple classification models
* Comparing model accuracy
* Selecting the best-performing model
* Saving the best model using Joblib
* Building a Streamlit web application for prediction

## 📊 Dataset Features

The model uses the following patient information:

* Age
* BMI
* Glucose
* Blood Pressure
* Cholesterol
* Insulin
* HbA1c
* Gender
* Smoking Status
* Physical Activity
* Family History

The target variable is:

* `Diabetes` — `0` for No and `1` for Yes

## 🤖 Machine Learning Models

The project trains and compares six classification algorithms:

1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier
4. Gradient Boosting Classifier
5. XGBoost Classifier
6. Support Vector Machine (SVM)

The model with the highest test accuracy is automatically selected as the best model.

## 🧹 Data Preprocessing

### Missing Values

Missing values in `Glucose` and `BMI` are replaced using their respective mean values.

Missing or invalid `Gender` values are handled using the mode.

### Duplicate Records

Duplicate rows are removed from the dataset.

### Outlier Treatment

The IQR method is used to detect and treat outliers in the `Blood_Pressure` feature.

### Categorical Encoding

The following categorical features are converted into numerical features:

* Gender
* Smoking Status
* Physical Activity
* Family History

One-hot encoding with `drop_first=True` is used.

## 🏆 Model Selection

All six models are trained using the same training and testing data.

Their predictions are evaluated using accuracy:

```python
accuracy_score(y_test, y_pred)
```

The model with the highest accuracy is selected and saved as:

```text
best_diabetes_model.pkl
```

3. Open Streamlit Community Cloud.
4. Connect your GitHub repository.
5. Select `app.py` as the main application file.
6. Deploy the application.
